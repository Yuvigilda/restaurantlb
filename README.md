# Nombre del Proyecto

Restaurantelb

##Tecnologías
-Frontend: React
Backend: Laravel
-Base de datos: MySQL

## Instalación

bash
# Clonar
git clone [https://gitgub.com/TU-USUARIO/TU-REPO.git](https://github.com/Yuvigilda/restaurantlb/tree/main)
cd TU-REPO

# Backend
 cd backend
 cp .env.example .env
 composer install
 php artisan key:generate
 php artisan migrate

 # Frontend
 cd ../frontend
 npm install
